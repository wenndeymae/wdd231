Technologies

This website uses HTML5, CSS3, JavaScript ES modules, the Fetch API, browser local storage, and the HTML dialog element. No CSS framework or JavaScript library is used.

Project Concept

Davao Milk Tea Hub is a fictional student project inspired by milk tea shops and local flavors in Davao City. It is not an operating business and does not accept real orders or payments.
